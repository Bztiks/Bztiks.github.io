Docker常用指令
2026-07-08|容器
Word count: 785|Reading time: 2 min

📦 镜像管理

操作 指令示例 说明
搜索镜像 docker search nginx 从 Docker Hub 搜索镜像
拉取镜像 docker pull nginx:latest 下载镜像到本地
列出镜像 docker images 或 docker image ls 查看本地所有镜像
删除镜像 docker rmi nginx 或 docker image rm nginx 删除指定镜像（需先删除使用它的容器）
强制删除镜像 docker rmi -f nginx 强制删除镜像
查看镜像详情 docker inspect nginx 查看镜像的详细信息

🚀 容器管理

操作 指令示例 说明
创建并运行容器 docker run -d --name mynginx -p 80:80 nginx 最常用的指令，后台运行并映射端口
列出运行中的容器 docker ps 查看当前正在运行的容器
列出所有容器 docker ps -a 查看所有容器（包括停止的）
启动容器 docker start mynginx 启动已停止的容器
停止容器 docker stop mynginx 优雅停止容器
强制停止容器 docker kill mynginx 立即停止容器
重启容器 docker restart mynginx 重启容器
删除容器 docker rm mynginx 删除容器（需先停止）
强制删除容器 docker rm -f mynginx 强制删除运行中的容器
进入容器终端 docker exec -it mynginx /bin/bash 进入容器内部进行调试
查看容器日志 docker logs mynginx 查看容器输出日志
实时查看日志 docker logs -f mynginx 持续跟踪日志输出
查看容器详情 docker inspect mynginx 查看容器的详细信息

🧹 清理与维护

操作 指令示例 说明
清理未使用资源 docker system prune 删除未使用的容器、网络、镜像和构建缓存
清理所有资源 docker system prune -a 更彻底地清理，包括未使用的镜像
删除所有停止的容器 docker container prune 清理已停止的容器
删除所有未使用的镜像 docker image prune 清理未使用的镜像
查看磁盘占用 docker system df 查看 Docker 占用的磁盘空间

📊 信息查看

操作 指令示例 说明
查看 Docker 版本 docker version 显示客户端和服务端版本信息
查看系统信息 docker info 显示 Docker 系统详细信息
查看容器资源占用 docker stats 实时查看容器 CPU、内存等使用情况
查看容器内进程 docker top mynginx 查看容器内正在运行的进程

🏷️ 镜像标签与保存

操作 指令示例 说明
给镜像打标签 docker tag nginx:latest myrepo/nginx:v1 为镜像添加标签，用于推送到私有仓库
导出镜像为文件 docker save -o nginx.tar nginx:latest 将镜像导出为 tar 文件
从文件导入镜像 docker load -i nginx.tar 从 tar 文件导入镜像

🐳 Docker Compose 常用指令

操作 指令示例 说明
启动所有服务 docker compose up -d 在后台启动 docker-compose.yml 中定义的服务
停止并移除服务 docker compose down 停止并移除容器、网络
重建并启动 docker compose up -d --build 重新构建镜像并启动
查看服务日志 docker compose logs 查看所有服务的日志
重启单个服务 docker compose restart app 重启指定服务
